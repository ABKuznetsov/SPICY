# SPICY SLIDES: плагин для ChatGPT

Версия плагина: **0.2.1**. Он содержит два навыка: создание редактируемых презентаций `.spicy` и создание самостоятельных виджетов, устанавливаемых в SPICY как `.spicy-plugin`.

[Скачать ZIP плагина ChatGPT](https://github.com/ABKuznetsov/SPICY/raw/refs/heads/main/chatgpt-plugin/SPICY-SLIDES-plugin-0.2.1.zip). [Посмотреть инструкции и сборщики](spicy-slides/).

## Установка из GitHub в рабочее пространство ChatGPT

Этот способ доступен администратору пространства с импортом плагинов из GitHub:

1. Откройте **Admin → Plugins → Add → Import marketplace**.
2. В **Source** укажите `https://github.com/ABKuznetsov/SPICY`.
3. **Path** оставьте пустым: каталог `.agents/plugins/marketplace.json` находится в корне репозитория. **Branch** — `main`.
4. Импортируйте каталог, разрешите доступ к GitHub и проверьте результат.
5. Найдите **SPICY SLIDES**, разрешите его использование и установите для нужных пользователей. В новом чате выберите плагин через `@`.

GitHub импортирует исходные файлы плагина; ZIP нужен для отдельного переноса. Импорт не устанавливает программу SPICY на компьютер. Условия доступа и обновления каталога описаны в [официальной инструкции OpenAI](https://learn.chatgpt.com/docs/enterprise/plugin-management).

## Личная установка через Plugin Creator

Если в вашем аккаунте доступен **Plugin Creator**, скачайте ZIP, откройте новый чат, выберите **@Plugin Creator**, приложите архив и отправьте:

> Создай для моего аккаунта приватный плагин SPICY SLIDES из приложенного пакета. Сохрани оба навыка create-spicy-slides и create-spicy-widget и все их references, assets, scripts и contract-lock.json. Не переписывай SDK и не меняй формат. Плагин должен создавать скачиваемые .spicy и .spicy-plugin, выполняя Python-сборщики и их проверки. Сначала установи его приватно, затем помоги проверить небольшой пример.

Следуйте шагам Plugin Creator. Для сборки нужен доступ чата к выполнению Python и файлам навыка. При переносе проверьте, что скрипты и их контрольные суммы сохранились. Если Plugin Creator или нужные возможности отсутствуют, обратитесь к администратору пространства. Скачивание ZIP само по себе не подключает плагин к ChatGPT. Общий порядок создания и вызова плагинов — в [официальной инструкции OpenAI](https://learn.chatgpt.com/docs/build-plugins).

Личная копия автора уже обновлена; её приватная ссылка не является публичной установкой для других аккаунтов.

## Использование

В новом чате выберите **@SPICY SLIDES**, приложите материалы и напишите, например:

> Создай презентацию SPICY на 10 слайдов для 15-минутного научного доклада. Текст и карточки должны быть редактируемыми. Используй приложенные материалы, не придумывай численные результаты. Выдай проверенный файл .spicy.

Или:

> Создай отдельно устанавливаемый плагин SPICY для интерактивной кристаллической структуры. В нём нужно открывать CIF, настраивать видимость атомов, ячейки и контактов, вращение и масштаб. После настройки вставлять модель как самостоятельный объект слайда. Выдай .spicy-plugin и краткую инструкцию.

SDK фиксирует структуру файла, проверяет ресурсы и контрольные суммы, отклоняет неизвестные поля и действия. Новый `.spicy` повторно читается после сборки. Это проверка формата; научное содержание и визуальный результат также нужно проверить.

## Установка созданного виджета в SPICY

Это отдельная установка, независимая от плагина ChatGPT и установщика редактора. Нужна версия SPICY с разделом **«Плагины»**; сборка программы для macOS сейчас проходит отдельную проверку и ещё не опубликована.

1. В SPICY откройте **Плагины → Установить или обновить…**.
2. Выберите созданный `.spicy-plugin`.
3. Нажмите **Настроить и вставить**, откройте CIF и настройте вид.
4. Нажмите **Вставить на слайд** и сохраните презентацию.

Каждый объект сохраняет собственные HTML, модель и настройки внутри `.spicy`. Обновление или удаление установленного плагина не меняет ранее вставленные объекты. Установленные плагины хранятся в пользовательском профиле; переустановка программы оставляет этот профиль, а очистка данных браузера может удалить библиотеку.

Шаблон CIF поддерживает core CIF с явными операциями симметрии и полностью занятыми позициями. Связи в примере — контакты по расстоянию внутри одной отображаемой ячейки, без полного периодического графа и без определения химических связей. Пользовательские CIF и презентации в пакет ChatGPT не включены.
