# SPICY SLIDES

Плагин для GPT-чата: загрузить старую презентацию и попросить «переделай и сделай интерактивнее» либо описать новую презентацию, получить редактируемый `.spicy` и доработать его в программе SPICY SLIDES.

Пакет включает навык `create-spicy-slides`, инструкции по чтению PPTX/PDF/HTML/SPICY, канонический шаблон, snapshot схемы текущего редактора и сборщик `.spicy` на стандартной библиотеке Python. Он не включает программу и не подключён к вашему аккаунту одним фактом скачивания. Сборщик проверен настоящим загрузчиком редактора; качество работы установленного навыка ещё нужно проверить на сайте.

## Подключение на сайте ChatGPT

В аккаунте с доступным **Plugin Creator** начните чат, выберите его через `@`, приложите пакет `SPICY-SLIDES-plugin.zip` и отправьте:

> Создай для моего ChatGPT плагин SPICY SLIDES на основе приложенного пакета. Включи навык create-spicy-slides и сохрани его инструкции, references, assets/starter.json, assets/schema.json и scripts/package_spicy.py как доступные навыку файлы. Пользователь загружает старую презентацию и просит переделать её и сделать интерактивнее либо задаёт промпт для новой. Результат — скачиваемый .spicy с отдельными редактируемыми объектами, вложенными карточками и действиями. Сборка файла требует среды выполнения Python. Не подменяй сборку пересказом инструкций. Сначала помоги установить плагин приватно и проверить пример.

Это подготовленный brief для Plugin Creator, а не проверенная команда автоматического импорта ZIP. Следуйте его шагам и убедитесь, что вспомогательные файлы доступны установленному навыку. Если создание плагинов или выполнение Python не доступно в вашем workspace, этот сценарий требует включения соответствующей возможности; не обещайте готовый файл без неё.

После установки в новом чате выберите **@SPICY SLIDES**, приложите старую презентацию и напишите:

> Переделай эту презентацию и сделай более интерактивной. Сохрани важное содержание, сделай текст и боксы редактируемыми, добавь полезные вложенные карточки. Выдай готовый файл .spicy для доработки в SPICY SLIDES.

Или:

> Создай презентацию SPICY SLIDES по этому описанию: [тема, аудитория, длительность, материалы]. Добавь интерактивные пояснения и выдай готовый .spicy.

Для Codex явный вызов навыка — `$create-spicy-slides`; на сайте ChatGPT используется `@`. Создание через Plugin Creator зависит от доступности в workspace. [Официальная инструкция OpenAI](https://learn.chatgpt.com/docs/build-plugins).

## Проверка перед использованием

Проверьте в установленном плагине четыре запроса: создать с нуля; переделать знакомый PPTX; добавить вложенную карточку к предыдущему результату; прочитать PDF с неясной формулой без выдумывания значений. Откройте результат в программе и выберите отдельную надпись и картинку в карточке. Проверьте наведение, click и повторный click. Сохраните и откройте заново. Техническая проверка сборщика не заменяет эти проверки GPT-чата.

Для пакета не нужен внешний MCP-сервер: инструкции и сборка файла работают в среде чата. Публикация в GitHub, подключение в аккаунте, публикация в публичном каталоге плагинов и переименование установленной программы — отдельные действия.


## Версия 0.2.0: фиксированная сборка и виджеты

Добавлен create-spicy-widget: автономный объект, CIF → настройка → сохранённый HTML → embed в презентации. SDK профиля spicy-gpt-authoring-v1 проверяет собственные SHA-256, отклоняет неизвестные действия и поля, проверяет ресурсы и повторно читает пакет. Для новых файлов используется author_spicy.py: модель описывает дизайн, структуру создаёт код.

Пример кристаллического виджета находится в skills/create-spicy-widget/assets. Поддерживается core CIF с явными операциями симметрии и полностью занятыми позициями; контакты задаются порогом расстояния. Поддержка всех CIF и универсальная научная интерпретация не обещаются. Пользовательские CIF и презентации в пакет плагина не включены.
