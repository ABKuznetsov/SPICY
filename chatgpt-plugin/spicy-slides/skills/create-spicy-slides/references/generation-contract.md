# Обязательный контракт создания файлов

Профиль `spicy-gpt-authoring-v1`: документ `1.0.0`, MIME `application/vnd.spicy.presentation+zip`, пакет `split-slides-v1`. Редактор поддерживает и другие пути импорта; этот плагин намеренно создаёт только проверенный профиль.

Не меняй `schema.json`, `starter.json`, `contract-lock.json` или код упаковщика, генератора и валидатора. Не исправляй ошибку сборки отключением проверки, переименованием поля, переписыванием SHA-256 или выдачей вручную собранного ZIP. Измени входное содержание в пределах контракта либо сообщи о неподдерживаемой возможности. Упаковщик проверяет контрольные суммы самого SDK, все связи документа, ресурсы и повторно читает готовый ZIP.

## Предпочтительный путь

Пиши небольшой файл дизайна и вызывай `scripts/author_spicy.py`. Генератор сам создаёт ID, сцены, дерево, контейнеры карточек, действия, metadata, embeds, SHA-256 и manifest. Вручную создавать native JSON для новой презентации не нужно.

```json
{
  "title": "Моя презентация",
  "language": "ru",
  "slides": [{
    "title": "Кристаллическая структура",
    "notes": "Заметки докладчика",
    "objects": [
      {"kind":"text","text":"Кристаллическая структура","x":80,"y":40,"width":1440,"height":90,"fontSize":44},
      {"kind":"widget","path":"structure-widget.html","x":120,"y":160,"width":1360,"height":650}
    ]
  }]
}
```

```sh
python3 scripts/verify_contract.py
python3 scripts/author_spicy.py design.json result.spicy --resource-root resources
```

Выходной файл должен отсутствовать. Успешный отчёт содержит `verified:true`. Только после него выдавай `.spicy`. При доступе к исходникам редактора дополнительно открой файл настоящим `format/package-reader.js`; он должен вернуть `editable:true`.

## Закрытые поля дизайна

- Корень: `title`, `language`, `slides`. Слайд: `title`, `notes`, `objects`.
- Общая геометрия объекта: `kind`, `name`, `x`, `y`, `width`, `height`, необязательный `rotation`. Координаты локальные; холст 1600×900.
- `text`: `text` или `markup` для `<strong>`, `<em>`, `<u>`, `<sub>`, `<sup>`; `fontSize`, `color` в hex. Никакого JS.
- `box`: `background`, `borderColor` в hex; `borderWidth`, `radius`.
- `image`: `path` относительно resource-root. SHA-256 вычисляется по исходным байтам, подпись — другой объект.
- `widget`: `path` к полностью настроенному, проверенному автономному HTML. Код и данные остаются внутри embed.
- `card`: `text`, `event:"click"|"hover"`, `panel:{x,y,width,height,objects}`. Внутри панели допускаются те же объекты и вложенные карточки.

Неперечисленные поля запрещены. Для визуальных эффектов и нестандартных алгоритмов создавай widget, не новые типы узлов. Native темы с произвольными токенами, секции старого вида, анимационные треки, transitions, variables и extensions не генерируются этим профилем. Структурные блоки и папки — `settings.presentationOutline`.

Для редактирования существующего совместимого JSON используй `package_spicy.py`. Если исходник содержит поддерживаемые редактором, но не этим профилем возможности, не удаляй их: используй штатный writer редактора или явно остановись на границе совместимости. Скрипт не мигрирует неизвестный формат молча.

## Разделение настроек

Параметры конкретного виджета разрешены только в JSON `spicy-widget-config` внутри его HTML: фиксированные поля `schemaVersion`, `widgetId`, `name`, `model`, `state`, `source`. Только `model/state/source` содержат данные конкретного алгоритма. Не добавляй `crystal`, `renderer`, `camera`, `plugin`, `buttons` в корень `.spicy` или в native content. У embed строго `bundleId` и `entryPoint`; metadata собирает генератор.

Проверка структуры не доказывает научную корректность данных и удобство интерфейса. Эти проверки сообщай отдельно.
