# Вложенные карточки и действия

## Владение

Объект с вложением — `component`, `content.role: "card"`. В его `children` находятся отдельный HTML-триггер с `role: "card-trigger"`, необязательные отдельные подписи и `frame` с `role: "card-panel"`. Триггер имеет локальную геометрию, обычно `(0,0)`. У панели `visible:false`, её дети используют координаты панели.

У панели `pluginData.contentViewport:{width,height}` — размер внутреннего холста. `pluginData.portalGeometry:{x,y,width,height,rotation}` — место открываемого окна на слайде. Это разные данные; перемещение окна не должно менять координаты его дочерних объектов. Вложенный `component` размещается в `children` панели, а не переносится в корень слайда. Смотри проверенный пример в `assets/starter.json`.

## Записи действий

Каждая запись `document.interactions[id]` содержит `id`, `ownerNodeId`, `trigger:{type:"hover"|"click"}`, `conditions:[]`, `actions:[]`, `enabled:true`. Владелец перечисляет ID записи в `interactionIds`. У записи только один владелец; не копируй его список на текстовую подпись, которая не должна реагировать.

| Намерение | Действие | Поведение |
|---|---|---|
| Временно показать при наведении | `show` | Цель видна в области взаимодействия, скрывается при выходе |
| Открыть по щелчку | `openPortal` | Окно остаётся открытым; повторный щелчок по тому же триггеру переключает его закрытие в текущем runtime |
| Явно закрыть окно | `closePortal` | Отдельная кнопка/объект закрывает указанную цель |
| Скрыть объект | `hide` | Скрытие указанной цели |
| Переключить видимость | `toggle` | Видимость объекта меняется по событию; не подменяй этим открытие окна |
| Перейти к слайду | `goto` | Цель — существующий ID слайда |

Для карточки используй `targetId`, `kind:"card"`, `geometry` открываемого окна. На одном владельце можно хранить независимые записи, например `hover → show → previewPanel`, `click → openPortal → detailPanel`. Цели могут отличаться. Никакой обязательной привязки «всегда открывать одно и то же» нет.

Не назначай `openPortal` и `closePortal` одновременно на один click: это не последовательность двух щелчков. Не создавай временное hover-показание через CSS, если должно сохраниться действие в редакторе. Не показывай надпись «Открыть вложение» у обычного текста без цели.

## Шаги и вкладки

В текущем формате групповые вкладки используют `selectTab` с `groupId`, `targetId`, массивами `panels` и `tabs`, `index`, `colors`. Массивы должны соответствовать друг другу; для нескольких шагов сначала проверь существующий пример/реализацию в доступной версии приложения. Не заменяй шаги скриптом внутри огромного HTML-блока: это нарушает редактируемость и синхронизацию. Если контракт конкретной анимации не подтверждён, оставь отдельные объекты и явно укажи, какое действие нужно настроить в редакторе.

## Проверка сценария

Наведи на триггер, переведи мышь в открытую область и на обычную подпись, выйди за область. Затем открой по щелчку и повтори щелчок. Проверь вложенную карточку: отдельный выбор картинки, перемещение, изменение размера и редактирование подписи. После сохранения и повторного открытия цели должны остаться прежними. Без доступа к приложению фиксируй это как список оставшихся проверок, а не как выполненные действия.
