# Интерактивный виджет для SPICY

Создай автономный HTML-виджет, который вставляется как один объект `embed`. Вокруг него остаются отдельные редактируемые заголовки, подписи и карточки. Сначала прочитай [фиксированный контракт](../create-spicy-slides/references/generation-contract.md). Параметры виджета не являются новыми полями `.spicy`. Не меняй SDK или его проверки ради необычного поведения.

## CIF → настройка → самостоятельный объект

Для кристаллической структуры используй готовые [HTML](assets/cif-widget.html) и [runtime](assets/cif-viewer.js), а не случайную реализацию парсера или придуманную структуру.

```sh
python3 ../create-spicy-slides/scripts/create_widget.py structure-widget.html --cif supplied.cif
```

Для предварительной обработки CIF нужен Node без сторонних библиотек; путь можно передать `--node`. Без Node создай авторский HTML без `--cif`: пользователь открывает его в браузере, нажимает «Открыть CIF», настраивает модель и сохраняет настроенный виджет. Пустую заготовку не вставляй в готовую презентацию и не выдавай за модель загруженного CIF.

Шаблон читает параметры ячейки, дробные координаты, типы атомов и явные операции симметрии. Для P1 допустима единичная операция; для других групп при отсутствии списка операций он отказывает вместо выдумывания симметрии. Поддерживает core CIF с полным заполнением позиций; несколько data-блоков, частичные заполнения, сложные выражения и слишком большие ячейки требуют отдельного подтверждённого решения. Не заявляй поддержку всех CIF.

Пользователь может вращать структуру мышью, менять масштаб колёсиком, включать атомы, связи по расстоянию и ячейку, скрывать элементы, менять размер атомов и порог расстояния. «Сохранить настроенный виджет» сохраняет модель, камеру и параметры в автономном HTML. Кнопки загрузки/сохранения нужны в отдельном авторском окне; внутри презентации остаются органы показа модели.

**Связи в этом шаблоне — геометрические контакты по выбранному порогу внутри отображаемой ячейки.** Это не определение химических связей, не полный периодический граф и не расчёт свойств. Для координационных полиэдров и точного периодического графа сначала установи правило построения и проверь его на данных; не добавляй научные результаты от себя. Исходные контактные данные и адреса авторов CIF в виджет не копируются: сохраняются научная модель и имя исходного файла.

## Отдельная установка в SPICY

Плагины SPICY устанавливаются независимо от программы. Выдавай `.spicy-plugin` отдельно от установщика редактора и от плагина ChatGPT. Это ZIP из ровно двух файлов: `manifest.json` и автономный `index.html`. Используй [упаковщик плагина](../create-spicy-slides/scripts/package_widget_plugin.py), а не ручную сборку:

```sh
python scripts/package_widget_plugin.py authoring.html cif-viewer.spicy-plugin --id cif-viewer --name "CIF Viewer" --version 1.0.0 --description "Configure and embed a crystal structure" --author "Artem Kuznetsov" --license "SPICY SLIDES Proprietary License"
```

Имя автора и лицензию бери из контекста проекта; не назначай пользователю чужую лицензию. `hostApi:1` фиксирован. При изменении содержимого повышай версию `major.minor.patch`. Установка: «Плагины → Установить или обновить…». Затем «Настроить и вставить»: открыть CIF, настроить кнопки и вид, нажать «Вставить на слайд». Каталог плагинов хранится в пользовательском профиле отдельно от программы. Каждый вставленный объект включает свою копию HTML, модели и настроек; обновление или удаление установленного плагина не меняет существующие презентации.

В авторском окне хост предоставляет `window.SpicyPluginAuthor`. Виджет регистрирует `SpicyPluginAuthor.exportHTML = () => savedHTML`, где `savedHTML` содержит текущие `model` и `state`, и удаляет из клона все `[data-spicy-plugin-host]`. Обработку запроса/ответа выполняет хост; не изобретай другой канал. В автономном HTML без хоста должна работать кнопка сохранения. Внутри презентации загрузка CIF скрыта, пока в авторском окне с `SpicyPluginAuthor` она доступна. Шаблон CIF уже реализует этот контракт.

## Другие виджеты и собственные кнопки

Для графика или схемы адаптируй HTML/CSS/JS внутри изолированного документа, сохранив внешний контракт конфигурации. `model` — исходные данные; `state` — камера, видимость, выбранный шаг и параметры; `source` — происхождение данных. Каждая кнопка должна менять подтверждённое состояние, не оставаться декоративной. Научные данные берутся из материалов пользователя.

Все CSS, JS, изображения и данные должны быть внутри одного HTML: inline classic scripts, inline style, изображения data URI. Редактор использует sandboxed srcdoc; относительные `script src`, `link href`, CDN, модули и fetch локальных ресурсов здесь не работают как в обычном сайте. Запрети их. Не вставляй widget-код в ordinary `html`-узел, не меняй sandboxProfile и не изобретай postMessage-канал.

Для разворота используй предоставленный хостом `window.SpicyEmbedFullscreen`; для обычного отдельного HTML — стандартный fullscreen. Исходные настройки должны быть записаны в конфигурацию HTML **до встраивания**. Не обещай сохранение произвольного custom `SpicyEmbedState` после переоткрытия: текущий editor initial-state имеет отдельный контракт для huntite. Живую синхронизацию, сохранение и snapshots проверяй отдельно.

## Проверка и выдача

1. Проверь автономный HTML через `../create-spicy-slides/scripts/widget_contract.py file.html`.
2. Проверь JS синтаксис Node `vm.Script` или в браузере; структура HTML сама по себе этого не доказывает. `create_widget.py` делает синтаксическую проверку, когда доступен Node.
3. Проверь исходные размеры ячейки, число операций, число атомов каждого элемента; не подменяй неизвестные координаты.
4. Проверь вращение, масштаб, кнопки, сброс и повторное открытие сохранённой конфигурации. При отсутствии браузера честно укажи, что эти сценарии не проверены визуально.
5. Для вставки используй [генератор презентаций](../create-spicy-slides/scripts/author_spicy.py), `kind:"widget"`, `path` к настроенному HTML. Выдай проверенный `.spicy` и отдельный HTML виджета. В существующий слайд пользователь может вставить его командой «HTML» редактора.

Никогда не выдавай файл с ошибкой проверки. Исправь входные данные либо явно сообщи о неподдерживаемой возможности. Не обходи проверки через ручной ZIP.
